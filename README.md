# PhotoShare

PhotoShare is a full-stack photo-sharing platform where event teams upload photographs, an Admin selects and publishes a gallery, and customers browse it using a shareable link and PIN without an account.

For persistent local MySQL and Cloudinary manual testing on Windows, use the [local backend startup guide](docs/LOCAL_DEVELOPMENT.md).

Current development status: the mandatory Spring Boot backend core is implemented and integration-tested. The React frontend, production object storage, cloud deployment, and final delivery documentation have not started.
